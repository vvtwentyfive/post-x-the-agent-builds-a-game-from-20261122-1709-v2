One prompt, one game: an AI agent built **Neon Breakout** — a tiny browser game in a single `game.html` file, no libraries. Move your mouse to catch the ball and clear all 50 neon bricks.

The video about the agent building it (prompt, terminal, game running, make.fun referral end card) is posted on X; its address is in `POST.json`. `main.ts` copies `POST.json` to the output directory after validating it.
